# 03: Applied AI Expanding Synapse & Token Stream Simulator

**What to build:**
A live interactive micro-simulator for the Applied Artificial Intelligence pillar. It renders a dynamic, expanding neural graph node tree illustrating generative token exploration and neural activation pathways. Nodes pulse and branch out organically with animated connecting edges, accompanied by a simulated streaming token ticker and attention weight indicators, visually explaining LLM agent orchestration.
