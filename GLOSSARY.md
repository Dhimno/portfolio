# Domain Glossary: Dhimas Reza (Dhimno) Portfolio

This glossary establishes the canonical terms and concepts used across the portfolio codebase, specifications, and UI components.

---

## 1. Core Engineering Pillars (`Pillars`)
The three foundational disciplines forming Dhimas's technical expertise:

- **Security Operations (`SecOps`)**: The discipline of active endpoint monitoring, anomaly detection, incident response, vulnerability assessment, and least-privilege identity governance. Encompasses tools such as EDR, SIEM (Wazuh/ELK), network packet analysis (Suricata, Wireshark), and threat intelligence.
- **Applied Artificial Intelligence (`Applied AI`)**: The practical implementation and architecture of Large Language Model (LLM) agents, retrieval-augmented generation (RAG), vector search systems, and automated machine learning inference pipelines.
- **Systems & Infrastructure (`Systems`)**: Native systems programming, low-level OS mechanics, containerization, and self-hosted infrastructure. Encompasses Rust, Tauri, Linux kernel/daemons, homelab cluster administration (Proxmox, Docker, reverse proxies), and performance-critical full-stack applications.

## 2. Interactive Console & Showcase Concepts
- **Minimalist Pixel Pillars**: Ultra-clean, unboxed specialization display consisting strictly of the section title "CORE ENGINEERING PILLARS", followed by the 3 iconic pixel/vector emblems in the center with their respective pixel font labels underneath. Completely strips away heavy card borders, background containers, and verbose text.
- **GameBoy DMG Classic Console**: The iconic 1989 dot-matrix handheld console aesthetic featuring a dual-tone warm gray chassis (`#dcdad2` to `#aaa79d`), dark slate bezel (`#5f5d72`), pea-green dot-matrix LCD screen (`#9bbc0f` background with `#0f380f` high-contrast pixel typography and CRT/matrix scanline overlay), magenta A/B buttons (`#a3235a`) set in an angled recessed pocket, red active battery indicator LED, and classic navy/purple labels (`#3b3a8c`).
- **Container Query Scaling (`cqw`)**: Architectural CSS pattern where all console geometry, button dimensions, typography sizes, and paddings scale strictly as fractions of the console wrapper's inline size (`cqw`) rather than static `px` or window-level `vw`, guaranteeing pixel-perfect proportional preservation across mobile (94vw) and desktop (`clamp(340px, 62vw, 980px)`).
- **Geometric Clip-Path D-Pad**: Directional cross with symmetrical directional indicators rendered strictly via CSS `clip-path: polygon(...)` to eliminate glyph asymmetry and cross-browser font rendering quirks.
- **Project ROM Cartridge Media (`rom-01.webp` .. `rom-06.webp`)**: Clean project captures rendered at exact 3:2 aspect ratio (1200x800px WebP, ~85 quality) without baked-in scanlines or filters, displayed with `object-fit: cover` and `object-position: top`. All CRT, scanline, and phosphor tint effects are rendered procedurally by the screen CSS layer.
- **CRT Retro Screen Filter**: Authentic CRT retro display treatment featuring horizontal scanlines, screen curvature vignette, phosphor color cast, and ambient glow directly layered over high-res project artwork.
- **Pure-Visual LCD Screen**: LCD viewport displaying strictly the project visual capture without any obstructive title banners, category chips, or HUD overlays inside the screen boundaries.
- **Scramble Glitch Typography**: Dynamic pixel-font title renderer that animates upon cartridge switching with rapid random alphanumeric character cycling (scramble/decode effect) before settling cleanly into the resolved project title.
- **Console Peeker Mascot**: Retro pixel character sprite that unpredictably peeks out from behind the top-left or top-right shoulder bumper of the GameBoy console.
- **Collapsible Project Archive**: Default-hidden project catalog section placed below the featured GameBoy showcase, expandable via a discrete toggle button `[+] LIHAT SEMUA PROYEK` to reveal the complete multi-project bento grid.
- **Project Cartridge (`ROM Cartridge`)**: The tactile physical representation of a project styled as a classic GameBoy gray cartridge with label artwork, sticker title, and top grip grooves.
- **Top Cartridge Bay (`Cartridge Slot`)**: The active slot along the top edge of the GameBoy console where a cartridge is inserted to load that project into the screen and below-console dossier.
- **Idle Blink Screen (`Empty Bay State`)**: The LCD screen state when no cartridge is inserted into the top bay, displaying a pulsing 8-bit green pixel message `MASUKKAN CARTRIDGE` / `INSERT CARTRIDGE`. Beneath the console, a stand-by title placeholder rendered in the identical `font-pixel text-lg sm:text-2xl` font announces `[ ENTER A CARTRIDGE ]` / `[ MASUKKAN CARTRIDGE ]`.
- **Standby Dossier Prompt (`Idle Bay Title Placeholder`)**: Typographic prompt rendered in the identical `font-pixel text-lg sm:text-2xl` styling at the exact position of the active project title when no cartridge is docked, instructing the user to enter a cartridge.
- **Unbounded Sky Physics (`Ceilingless Playfield`)**: Physics sandbox configuration with an infinite vertical ceiling (`overflow: visible`) and tall guide walls extending high above the viewport, allowing ejected or flung cartridges to soar freely across upper section headers and obscure elements before falling naturally back to the base floor.
- **Full-Bleed Horizontal Gutter (`Edge-to-Edge Arena Span`)**: Horizontal sandbox configuration spanning the complete viewport width (`100vw`) with side colliders pinned to screen edges, giving cartridges unlimited side-to-side room across the display.
- **Cartridge Physics Floor (`Ground Plane`)**: The simulated 2D physics boundary at the base of the showcase powered by Matter.js where unslotted cartridges rest, collide, tumble, and can be dragged or flung with realistic momentum, restitution bounce, and gravity.
- **Persistent Physics Sandbox**: Rigid-body state behavior where dragging or tossing a cartridge leaves it at its dynamic resting position on the playfield floor rather than reverting to a predetermined static grid slot.
- **Magnetic Snap Receptacle**: Proximity threshold around the GameBoy top slot that pulls an active dragged or flung cartridge smoothly into socket lock with synthesized mechanical latch audio.
- **Cartridge Eject Impulse**: Physical interaction (click/drag out or swap) that applies an upward impulse velocity to the slotted cartridge, tossing it back into the physics playfield.
- **Mobile Tap-to-Slot**: Single-touch accessibility pattern allowing users to tap any resting cartridge to smoothly slot it into the GameBoy without requiring manual drag-and-drop.
- **Mobile ROM Shelf (`Cartridge Grid Rack`)**: Dedicated responsive 3-column × 2-row cartridge storage rack rendered strictly on mobile viewports (< 768px) directly above the GameBoy console, bypassing 2D Matter.js physics simulation for deterministic touch navigation and zero viewport clutter.
- **Guided Docking Transition (`Cartridge Slide-to-Slot`)**: Coordinated trajectory animation moving a selected cartridge from its stationary rack coordinate downward into the GameBoy slot bay, reversing on ejection.
- **Ghost Shelf Receptacle (`Empty Socket Silhouette`)**: A recessed dashed outline or silhouette placeholder preserved in the mobile 3x2 shelf grid at the exact index of an active docked cartridge, visually indicating its origin and return destination.
- **Central Physics Deflector & Console Shield (`Chassis & Dossier Barrier`)**: Invisible static rigid body colliders encompassing the GameBoy console chassis and below-console project dossier, repelling dropping or thrown cartridges into flanking gutters and guaranteeing an unobstructed view of both the console controls and technical project copy.
- **Handheld Horizontal Layout (`DMG Horizontal Chassis`)**: Wide-body handheld layout with D-Pad and diagonal SELECT/START controls unified on the left wing, LCD viewport in the center, and carved magenta A/B buttons on the right wing.
- **Flanking Cartridge Trays (`Side Gutters`)**: The designated left and right physical zones flanking the central project dossier where unslotted cartridges naturally settle and remain accessible for tactile dragging and tapping.
- **Carved Action Button Well (`DMG Button Well`)**: The authentic recessed oval pill pocket angled at -25° on the right GameBoy chassis containing the magenta circular B and A buttons in their classic layout, accompanied by the diagonal text labels.
- **Top Clearance Buffer (`Console Headroom`)**: The structural spatial margin (minimum 80px) provided above the GameBoy console chassis ensuring the top cartridge slot bay, peeking mascots, and docked cartridge tabs are fully visible without clipping against parent container overflow boundaries.
- **True-to-Sticker CRT Rendering**: LCD display pipeline that preserves the crisp native colors, contrast, and typography of project captures with subtle dot-matrix scanlines and zero dark-multiply mud, ensuring 1:1 visual parity between cartridge sticker artwork and active screen presentation.
- **Dynamic Eject Awakening (`Awakened Body Impulse`)**: Mechanical ejection state transition that explicitly resets a cartridge's Matter.js physics body state (`isStatic: false`, waking sleep state) while applying an upward and outward velocity impulse, guaranteeing natural gravitational tumble back to the physics floor.
- **Staggered Spawning Grid**: Initialization logic that drops cartridges across spaced horizontal lanes and staggered drop heights to ensure cartridges settle side-by-side cleanly without piling up illegibly.
- **Title-Isolated Glitch Transition**: Scramble transition effect applied strictly to `GlitchTitle`, ensuring project descriptions remain crisp and readable without any flickering artifact.
- **Stage-Shift Project Drawer**: Interactive state transition triggered by pressing [A] / Enter or clicking the screen, moving the console slightly to the left and unrolling the comprehensive technical dossier to the right. Pressing [B] / Esc dismisses the dossier.
- **Retro-Pixel Aesthetics**: Deliberate visual design system leveraging 8-bit pixel fonts (`Silkscreen`), stepped pixel border corners, scanline textures, and synthesized Web Audio API frequency beeps.

## 3. Retro-Pixel UI System (`Retro UI`)
- **Pixel Segmented Chassis**: Segmented filter bars, tab switches, and button controls featuring stepped pixel-cut corners, monospace brackets `[ OPTION ]`, and solid high-contrast active fills.
- **Retro-HUD Typography**: Dual-layer typographic hierarchy combining `Silkscreen` (`font-pixel`) for headings, navigation links, badges, filter labels, and buttons, with `JetBrains Mono` (`font-mono`) for crisp, high-density body copy.
- **Stepped Pixel Card Framing**: Pixelated stepped polygon clip-paths or discrete pixel-cut borders replacing generic curved radiuses (`rounded-2xl`) across Projects, Experience, and Contact surfaces.
- **8-Bit Tactile Micro-Interactions**: Web Audio API synthesized soft clicks triggered on tab switches, paired with custom 8-bit pixel pointer cursors.
- **Mobile Experience Accordion (`Multi-Expand Timeline`)**: Responsive disclosure interaction pattern on mobile viewports (< 768px) where timeline cards in Experience/Education render initially in a compact title/organization view with a retro `[+] DETAIL` / `[-] TUTUP` indicator, expanding smoothly downward via Framer Motion height transitions upon tap to reveal bullet highlights and focus tags.
- **Edge-Clamped Dialogue Bubble (`Viewport Boundary Guard`)**: Dynamic auto-repositioning mechanic in `DialogueBox` on mobile screens (< 768px) that calculates the speech bubble's viewport boundaries and shifts its horizontal offset inward by the exact pixel delta when a companion character wanders near the left or right screen edge, preserving a safe 12px viewport margin while adjusting the speech arrow tail so it continues pointing squarely at the character.
- **Mobile Console Spatial Buffer (`Shelf-to-Console Headroom`)**: Dedicated vertical separation buffer (minimum 48px / `mb-12`) positioned between the bottom row of the mobile 3x2 cartridge rack and the top shoulder bumpers/cartridge slot of the GameBoy console, ensuring shoulder bumpers, cartridge slot bay, and peeking mascot sprites have ample breathing room.
- **Mobile DMG Control Re-alignment (`Pill Button Interior Guard`)**: Device-specific CSS geometry rules for `.gb-ss` (START & SELECT) on mobile screens (< 768px) that elevate the button pair (`bottom: 4.5%`) and shift it rightward (`left: 53%`), adjusting label offset (`top: calc(100% + 2px)`) so buttons and text labels remain fully contained inside the console's gray chassis without overflowing over rounded corner edges.
- **Drawer-Encapsulated Locale Switcher (`Mobile Drawer LangToggle`)**: Responsive navigation architecture where the multi-language selector is hidden from the top app bar on compact screens (`< 768px`) and rendered strictly within the expanded mobile hamburger drawer menu, keeping the top header minimal while allowing language toggles without prematurely closing the drawer.
