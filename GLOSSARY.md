# Domain Glossary: Dhimas Reza (Dhimno) Portfolio

This glossary establishes the canonical terms and concepts used across the portfolio codebase, specifications, and UI components.

---

## 1. Core Engineering Pillars (`Pillars`)
The three foundational disciplines forming Dhimas's technical expertise:

- **Security Operations (`SecOps`)**: The discipline of active endpoint monitoring, anomaly detection, incident response, vulnerability assessment, and least-privilege identity governance. Encompasses tools such as EDR, SIEM (Wazuh/ELK), network packet analysis (Suricata, Wireshark), and threat intelligence.
- **Applied Artificial Intelligence (`Applied AI`)**: The practical implementation and architecture of Large Language Model (LLM) agents, retrieval-augmented generation (RAG), vector search systems, and automated machine learning inference pipelines.
- **Systems & Infrastructure (`Systems`)**: Native systems programming, low-level OS mechanics, containerization, and self-hosted infrastructure. Encompasses Rust, Tauri, Linux kernel/daemons, homelab cluster administration (Proxmox, Docker, reverse proxies), and performance-critical full-stack applications.

---

## 2. Interactive Console & Simulator Concepts
- **Live Simulator**: A reactive canvas or CSS/SVG micro-widget embedded directly within a pillar card, illustrating real-time domain behavior (e.g. radar ping for SecOps, neural node flow for AI, server status terminal for Systems).
- **Tech Arsenal (Matrix)**: The discrete list of battle-tested tools, protocols, and runtimes associated with each engineering pillar, revealed through user interaction.
- **Retro-Pixel Aesthetics**: Deliberate visual design system leveraging 8-bit pixel fonts (`Silkscreen`), stepped pixel border corners, scanline textures, and synthesized Web Audio API frequency beeps.
